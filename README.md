# 🏦 Banking Application (Python)

A console-based banking application developed using **Core Python**, designed to simulate real-world banking operations with a focus on security and user interaction.

## 🚀 Features
- User Signup & Login system
- Password validation and secure input handling
- Credit and Debit transactions
- Balance inquiry
- Password reset functionality

## 🛠️ Technologies Used
- Python
- Core Python concepts (loops, functions, conditionals, dictionaries)
- Secure input handling using `getpass`

## 📂 Project Structure
- `My_Bank_Application.ipynb` – Main application logic and execution

## 🎯 Learning Outcomes
- Practical understanding of Python fundamentals
- Implementing secure user authentication
- Handling real-world logic using structured programming
- Improving problem-solving and logical thinking
